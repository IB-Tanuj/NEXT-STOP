Key Endpoints
Endpoint	                             Description
GET /search	                 Search available trips between two cities — returns fares, amenities (WiFi, power), seat counts, brand logos, intermediate stops, and platform fees
GET /autocomplete            City autocomplete search — get city UUIDs for use in other endpoints
GET /cities	                 Full list of all FlixBus cities with coordinates and country — unique to this API
GET /cities/:id	             City detail with activities and points of interest — ideal for travel content apps
GET /cities/:id/reachable	 All destinations reachable from a city with prices — the highest-value endpoint for "where can I go?" features
GET /timetable	             City departure timetable — all departures from a city on a given date

NOTICE : for all snippet code of all endpoints the Target and Client are same 
  Target:JavaScript        Client:XMLHttpRequest

  HOST = flixbus-api2.p.rapidapi.com
